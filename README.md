# anita-manion

Professional website for Anita Manion, PhD — Associate Professor of Political Science and Director of Undergraduate Studies at the University of Missouri–St. Louis, and political analyst for KSDK News.

Live site: https://manion228.github.io/anita-manion/

## Structure

- `index.html` — single-page site (overview, research, media, recognition, teaching & service, contact)
- `styles.css` — all styling, light/dark theme support
- `assets/` — headshot and downloadable CV

## Updating content

Edit `index.html` directly. Publications, awards, and media stats are sourced from Anita's CV (`assets/Anita-Manion-CV.docx`) — keep that file current and refresh the page content when it changes.
